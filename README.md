### Resumen

[Enunciado](https://github.com/maximdorogov/fundamentos-de-vision-fiuba/blob/main/trabajos_practicos/tp3/tp_3_enunciado.png).

El objetivo del trabajo es la detección automática de una plantilla que representa un logo de Coca Cola en varias imágenes que pueden poseer uno o más logos.

Para ello, se prueba tanto con el enfoque de **template matching** como con la extracción y comparación de características locales con **SIFT**.
